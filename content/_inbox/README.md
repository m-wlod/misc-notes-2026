# Inbox

Raw source notes (NotebookLM exports, book notes) for one lesson each, with front matter `lesson: <id>` and `sources`. `pnpm content:draft content/_inbox/<note>.md` turns a note into `<note>.brief.md` for a writing session (see `docs/CONTENT_GUIDE.md` §8).

These are sources, not publishable text: lessons are written in our own words and cite the book. Briefs are working files and are not committed.
