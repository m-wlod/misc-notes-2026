## Why it matters

We teach maths, so an error in the content is an error in learning. We want every error to be easy to report and quick to fix, and every significant change to be visible.

## How to report an error

- In lessons and exercises, use the “Report an error” button. Describe what is wrong and what it should be; if you can, point to a source.
- In Debunk Lab entries, suggest a correction on the entry, for example when a quote is incomplete, a date is wrong or a new source has appeared.

## Review

Reports are checked by moderators. We aim to review every report within 7 days [to be completed: confirmation of the target]. An accepted correction earns the reporter 50 XP.

## Sources

Lessons cite their sources: book, chapter and page. Debunk Lab entries show where a claim was made, with its date and an archived copy, so that anyone can check the original.

## Debunk Lab verdicts

Each claim receives one of these verdicts:

| Verdict | Meaning |
| --- | --- |
| False | the claim contradicts the maths or the data |
| Misleading | it contains some truth, but as a whole suggests a false conclusion |
| True but irrelevant | it is correct but does not support the conclusion it is used for |
| Depends | whether it holds depends on assumptions, which the entry explains |

A verdict concerns the claim, not the person who made it.

## Marking corrections

Significant corrections are noted on the page concerned, with the date of the change. Minor editorial changes, such as typos, are made without a separate note.
