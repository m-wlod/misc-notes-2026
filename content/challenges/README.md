# Weekly challenges (Phase 15)

One file per week: `<monday>.yaml`, where `<monday>` is the week's Monday (YYYY-MM-DD,
Europe/Warsaw, the same weeks as the leagues). Fields: `id`, `week`, `deadline` (ISO with
offset), `title`, `prompt`, `rubric` (each `{ pl, en }`), `status` (`draft` | `published`).
Only published challenges are shown. Real challenges are content: written later.
